# CivicBridge

## Project Overview
CivicBridge connects community members with
local resources and essential services.

## Main Features
- Community resource directory
- Search and filtering
- Category-based navigation
- Interactive resource finder
- Responsive website design

## Technologies
- React
- TypeScript
- Vite
- Tailwind CSS

## AI Assistance
Google AI Studio was used to generate the initial
website code and design. AI assistance is disclosed
in accordance with applicable FBLA guidelines.
